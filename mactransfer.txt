Goal
Set up the project on macOS from GitHub and run the FastAPI app locally.
Before Leaving Current Device
Make sure everything is pushed to GitHub:
git status
git add -A
git commit -m "Refactor app into routers models and data"
git push
Then check GitHub in browser and confirm you see:
app/main.py
app/data.py
app/models.py
app/routers/nef.py
app/routers/nwdaf.py
requirements.txt
README.md
.gitignore
Mac Setup
Install Homebrew if you do not have it:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
Install needed tools:
brew install git python
Check versions:
git --version
python3 --version
pip3 --version
Clone Project
Create projects folder:
mkdir -p ~/projects
cd ~/projects
Clone your repo:
git clone https://github.com/YOUR_USERNAME/5g-core-api-sandbox.git
cd 5g-core-api-sandbox
Replace YOUR_USERNAME with your GitHub username.
Check repo:
git status
Expected:
On branch main
Your branch is up to date with 'origin/main'.
nothing to commit, working tree clean
Create Virtual Environment
Inside the project folder:
python3 -m venv .venv
source .venv/bin/activate
Your terminal should show:
(.venv)
Upgrade pip:
python -m pip install --upgrade pip
Install project dependencies:
pip install -r requirements.txt
Run App
Start FastAPI:
python -m uvicorn app.main:app --reload
Open in browser:
http://127.0.0.1:8000/docs
Test health endpoint:
http://127.0.0.1:8000/health
Expected:
{"status":"ok"}
Test With Curl
Open second terminal:
cd ~/projects/5g-core-api-sandbox
source .venv/bin/activate
Create subscription:
curl -X POST "http://127.0.0.1:8000/nef/subscriptions" \
  -H "Content-Type: application/json" \
  -d '{"ue_id":"001","event_type":"ue-status-change","callback_url":"https://example.com/callback"}'
List subscriptions:
curl -s "http://127.0.0.1:8000/nef/subscriptions" | python -m json.tool
Delete subscription:
curl -X DELETE "http://127.0.0.1:8000/nef/subscriptions/sub-001"
Important Notes
.venv is not downloaded from GitHub. You recreate it on every device.
Your code comes from GitHub. Your dependencies come from:
requirements.txt
If you restart the API, subscriptions disappear because they are stored only in memory for now.
